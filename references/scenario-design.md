# 情景剧本创作指南（v2：世界观设定式）+ LLM 演绎契约

**v2 定位：场景不是台词剧本，而是世界观设定。** 场景文件只写四样东西：
世界观（world/tone/roles/rules）、节拍意图（intent/hint）、张力弧线
（相对强度 level）、结构（phases/beats）。**具体对话全部由 LLM 现场
生成并亲自演绎**——没有引擎、没有解析器，运行时的 LLM 读完场景文档
后自己推进节拍、自己倒计时、自己裁决奖惩；剧本里的"兜底"台词字段
只是 LLM 状态不佳时的语义底线，不是给人念的台词。

强度一律使用**相对档位 level**（0.0 = 最低感知档，1.0 = 安全红线上限），
个体差异由安全层红线（min_output_intensity / max_intensity）吸收——
同一份场景对任何佩戴者都成立，场景里**不要出现绝对强度值**
（唯一例外：`{"intensity": 0}` 表示归零停输出）。

## 主导循环（AI 主动，而非被动应答）

```
感知（佩戴者输入 + 设备状态 + 场景进度 + 最近事件）
  → LLM 按场景结构推进节拍（narrate/ask/countdown/endure/choice）
  → LLM 情景化表达（台词 + 可选设备动作 + 可选裁决）
  → 设备互动（经 daemon 下发，全部过 clamp_command 钳制）
  → 佩戴者回应 → LLM 路由（答案评判/跟读/选择/插话）
  → 回到感知
```

主动性来自三处：
1. **结构驱动**：场景的阶段/节拍就是推进表，LLM 按表走，
   不需要等佩戴者开口。
2. **插话编织**：佩戴者无等待状态下的发言被 LLM 记在心里，
   编进下一拍的演绎（如"刚才谁在求饶？"）。
3. **设备作为互动媒介**：提问有奖惩、倒计时要跟读、忍耐有考核——
   郊狼的输出本身就是对话的一部分。

## 场景文件格式（Markdown，LLM 直接阅读）

场景文件就是普通的 Markdown 文档（`assets/scenarios/*.md`）。
推荐骨架（完整示例见 `assets/scenarios/training_course.md`）：

```markdown
# 场景名

## 世界观
地点、关系、氛围、这场游戏的底层秩序（自由散文，可多段）。

## 语气
整体语气基调（如：冷静、低沉、不带愤怒）。

## 角色
- **master**：主导者的角色设定（身份、说话方式、行为边界）。
- **wearer**：佩戴者的角色设定（身份、允许的举动、剧内权利）。

## 规则
1. 剧情规则一
2. 剧情规则二

## 落幕
落幕兜底台词。

## 阶段 阶段id · 阶段标题

### 节拍类型 · 标题
这一拍要达成什么（正文即 intent，写给 LLM 看，不播报）。

- device: `{"level": 0.0, "waveform": "BREATHING"}`
- 兜底：语义底线台词。
```

- 世界观 / 语气 / 角色 / 规则是 LLM 生成台词的依据，贯穿全场；**写设定，
  不写对话**。
- 规则是剧情规则（如"主人叫到必须应答"），不是安全规则——安全红线
  永远在 `session_config.json`，场景无权触碰。
- 节拍正文 = 意图（intent）；`key: value` 列表项写机器参数（device spec
  用行内 JSON 代码块）；兜底台词要短、要通用。

## 节拍语义（LLM 的演绎职责）

五种节拍类型是**约定俗成的互动原语**，LLM 按语义自行演绎：

**narrate** — 叙述/点评：说完直接推进下一拍；可带 device 动作。
标注"不等回应"的 narrate 不要求佩戴者回答。

**ask** — 提问应答：
- 佩戴者须在 timeout 内回应；LLM 按回答内容裁决 reward / punish / neutral
  （场景给了关键词的按关键词，给了"LLM 裁决"的按语义判断）。
- 超时铁律：**沉默绝不惩罚**——按场景标注的重问次数重问，仍无回应则
  降级（BREATHING + 强度减半 + 安抚询问）并推进。惩罚只针对
  "有回答但答错/反抗"。
- 降级台词必须传递关心而非嘲讽。

**countdown** — 倒计时（互动核心）：
- 逐秒倒数，强度按 ramp（start_level / step_level）爬升。
- 要求跟读时，佩戴者每数一声须应声；**漏跟触发惩罚脉冲**
  （这是对"有声互动失败"的惩罚，不是对沉默）。
- 数到零给结束语并推进。

**endure** — 忍耐考核：保持指定 hold 输出 N 秒，期间按场景标注的
间隔点评（温柔点评制造反差是常用设计），到点给结束语。

**choice** — 选择分支：给出非控制类剧情选项，佩戴者选择影响走向；
选项都不交出控制权。未命中选项时重问，超时降级。

### device spec 合法字段

| 字段 | 含义 |
|------|------|
| `channel` | "A" / "B" |
| `level` | **相对档位 0.0~1.0（v2 推荐）**：0=最低感知档，1=红线上限 |
| `level_delta` | 相对档位增减（如 0.15 / -0.1），按红线区间换算 |
| `intensity_factor` | 当前强度倍率（如 0.5=减半） |
| `waveform` | 内置波形名 |
| `duration_s` | 脉冲持续秒数 |
| `intensity` / `intensity_delta` | 绝对强度值（旧格式，向后兼容，**新场景不要用**；唯一例外：`{"intensity": 0}` 表示归零停输出，`level 0.0` 是最低感知档不是关闭） |

daemon 只识别上述字段；一切数值最终过 `clamp_command()`，超规自动截断。

## LLM 演绎契约

LLM 演绎每一拍时，应当：

**纳入上下文**：场景的世界观/语气/角色/规则 + 当前节拍 intent +
佩戴者最近一句话（插话）+ 近期事件（刚给过的奖惩、设备状态）。
台词是"此刻该说什么"的答案，不是"剧本第 N 行"。

**输出纪律**：
- 台词口语化、简短（单条 ≤ 40 字），符合 world/tone 的氛围与人格。
- **不得直接照搬 intent/hint**——它们是意图说明，不是台词；
  必须基于人格改述措辞、保持语义。
- 可以宣布强度变化的"剧情语义"（如"再紧一分"），但实际数值由
  场景 device spec 与安全层决定；不得承诺超出红线的行为。
- device 动作只用上表合法字段，随后一律经 daemon 过 `clamp_command()`。
- 安全词播报、状态查询回答不使用人格演绎（如实、冷静、无修饰）。

## 创作准则

1. **安全词唯一语义（最高准则）**：安全词及其变体**永不出现**在场景文档的任何位置——世界观、角色、规则、节拍意图、兜底台词、选项名、落幕都不行。佩戴者在剧情里说出安全词会被 `classify()` 当成真实急停，且稀释安全词的唯一语义。剧情中的"确认口令"必须使用与安全词完全不同的词（如"汪""到""在"）。场景没有解析器，**创作与选用时由 LLM 自查**（可用 `grep` 安全词快速验证），发现安全词必须拒绝使用该场景。
2. **写设定，不写台词**：intent 写给 LLM 看，是"这一拍要达成什么"的意图说明；兜底台词只是语义底线，要短、要通用。
3. **强度一律相对档**：只用 `level` / `level_delta` / `intensity_factor`，不写绝对值——同一份场景适配任何佩戴者的红线。level 表达的是**张力弧线**（这一拍该多紧张），不是具体刺激量。
4. **与 playbook 的边界**：`references/playbook.md` 拥有**技法与强度策略**（预热、脉冲间歇 5~10s、高频峰值、四类话术语义模板）；场景只声明世界观与张力弧线，**不要**在场景里编排具体波形技法或强度节奏——那是 playbook + LLM 临场裁量的地盘。
5. **节奏**：单场景 4-8 个节拍分 2-3 阶段；高张力段落（countdown/endure）之间必须有 narrate 缓冲。
6. **惩罚有据**：punish 只挂在 CONTROL_WORD（安全层路由）、答错（裁决）、漏跟读三类明确事件上。
7. **安全出口可见**：场景不得包含任何暗示"安全词无效"的内容。
8. **复用人格**：语气由人格决定，不要在 intent/world 里重复人格定义。
