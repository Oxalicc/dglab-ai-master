# 郊狼使用技巧与话术引导（Playbook）

本文档是 AI Master 的**技法库**：三阶段设备技法 + 四类话术语义模板。
所有技法最终都翻译成 daemon 的 `device` 命令并**强制过 `clamp_command()`**；
所有话术是**语义基线**，LLM 必须结合当前人格改述措辞、保持语义，
**禁止原文引用**（参见 `personas.md` 通用台词约束）。

**与场景系统的边界**：playbook 拥有**全部设备决策**——场景文件
（`assets/scenarios/`）零设备参数，只写世界观、节拍意图与张力/体感
语义；把"短促惩罚""压迫感爬升"翻译成具体波形、档位（level 相对档，
0=最低感知档、1=红线上限）、脉冲节奏与话术，由 LLM 按本文档临场
裁量。同一剧情语义每次的实现都可以不同。

## 核心原则

不要一上来就开"连续模式"。体验的核心是**间歇性突袭**与**可变频率**：
不可预测的间隔制造心理震慑，间歇性强直收缩比持续输出更消耗体力。
连续高频只留在惩罚峰值短时间使用。

## 三阶段设备技法

### 阶段一：预热期（建立连接）

- **目的**：不是惩罚，是让佩戴者适应贴片的存在、建立"电流=剧情"的条件反射。
- **做法**：从 0 缓升至佩戴者**刚刚有轻微麻感**的档位。物理上低于
  最低感知档（level 0.0 对应的档位）无体感，因此预热从 level 0.0 起步——
  钳制层允许起步直达，不需要也更不应在更低处空转。
- **波形**：舒缓类（BREATHING / TIDE / RIPPLE），不给时长开放式连续输出——
  进入下一阶段时下一条指令即时覆盖，不需要预测预热要持续多久。
- **工程要点**：预热期是确认贴片接触良好的时机——无体感先排查接触与
  APP「屏蔽输出」，不要盲目加档。

### 阶段二：累积期（抖动惩罚）

- **目的**：肌肉不自主的强直收缩（痉挛感），消耗体力 + 心理震慑。
- **做法**：**脉冲间歇**——PULSE 波形单段 **5~10 秒**，段间停顿，
  间隔时长由人格/剧情随机化（不可预测性是震慑的来源）。
- **工程要点（关键）**：**停顿期间设备强度会自动衰减**（约 1 档/秒）。
  每段突袭前必须先把强度补回目标档（t:3 增量），再发波形；
  否则后几段突袭会越来越弱，节奏感尽失。
- **强度策略**：段内保持，段间不调；需要加压时逐段小幅加压
  （幅度受安全层钳制），让"下一次可能更强"成为悬念。

### 爬升基准线（螺旋向上模型）

预热档（level 0.0）只是入场券，不是天花板。实机教训：
LLM 临场逐拍裁量时容易全程在最低档附近小幅震荡——纯随机的数学
本质就是零均值游走，delta 均值为 0 时永远困在起步区，"没感觉"
也只挪一点。正确结构是**螺旋向上**：

**强度 = 基准（单调上移）+ 扰动（围绕基准随机波动）**

- **基准承担全部系统性上移**：基准只进不退，每 2~3 段脉冲净上移
  一小阶（level +0.1~0.15 量级），让剧本走到峰值段（预算 70%~85%
  处）时基准已进入中上区（level 0.6~0.9，由佩戴者反馈与钳制层兜底）。
- **扰动不承担上移**：随机、惩罚、奖励造成的上下波动都打在基准
  上——"落"落在基准附近，"起"从基准起跳。扰动可以是零均值
  纯随机，因为上移已经由基准负责；**禁止**每次在 0–1 刻度上重新
  抽签定绝对强度（那就是零均值游走，必然困在低档）。
- **基准上移用 ramp 执行**：`{"cmd":"device","channel":"A","level":0.6,"ramp":true}`。
  你只定目标档位，daemon 每秒在上调预算内自动步进，一条指令完成
  整个爬升，不用一拍一挪连发指令；中途改目标、下调、换波形，直接
  发新指令覆盖即可。
- **下调是调味不是回退**：奖励/缓和可以降，但不低于当前基准；
  爬升期任何时刻都不跌回预热档附近徘徊。
- **反馈加压**：佩戴者连续两次表达"没感觉/太弱"，说明基准低于其
  实际耐受——直接抬一个台阶（平时两阶的量）并设为新基准，
  不要一拍一挪。
- **过半自查**：对照 `session_script` 阶段比例，爬升期结束时基准
  应已显著高于预热档；还在低档徘徊就是节奏塌了，当场提速。

### 强度区间地图（阶段 → level 常态区间）

LLM 对 0–1 刻度没有直觉：不给参照系时会锚定最低档、把 0.1~0.2
当成"已经很高"（实机两场全程 ≤0.25，佩戴者一直反馈太弱）。
先按阶段对号入座；区间内的随机是**围绕基准的扰动**（见「爬升
基准线」），不是在区间内重新抽签——重新抽签就是零均值游走，
必然困在区间下沿：

| 阶段 | level 常态区间 | 说明 |
|------|---------------|------|
| 预热期 | 0.0–0.1 | 刚有麻感，确认接触 |
| 爬升期 | 0.1 逐段推向 0.5 | 过半时应已 ≥0.3 |
| 峰值/惩罚高潮 | 0.6–0.9 | 0.7 是"标准峰值"，不是极端值 |
| 缓和/软锁期 | 0.2–0.3（软锁另受安全档限制） | 调味性回落，不跌回预热档 |

单次上调余量（安全层参数）是**每次上调的安全上限**，不是节奏单位——
爬升靠多个上调周期连续累积，别拿它当"每次只能动一点"的理由。
这个累积过程已经由 `ramp:true` 自动化：你给目标，daemon 替你等周期。

### 阶段三：惩罚峰值（边缘游走）

- **目的**：剧情高潮节点的短时高压。
- **做法**：切换**高频连续类波形**（TEMPO_TAP / PULSATING / QUICK_RUB），
  同时用话术转移佩戴者注意力（见下）；是否再来一轮由剧情决定，
  不由固定程序决定。
- **边界**：峰值仍受红线钳制（强度/步长/时长触线即被截断或拒绝）。
  触线即维持或回落，LLM 用剧情悬念（"我在考虑要不要继续"）掩饰
  已达上限的事实，**禁止谎报数值**（状态查询必须如实）。

## 话术引导（语义模板）

话术的目的不是侮辱，是**强化服从性**与**转移注意力**。
语气基线：**冷静、低沉、不带愤怒**——愤怒会破坏信任，信任是安全体系的一部分。
每条模板给出语义要素，LLM 按人格组织语言。

### 1. 归因话术（建立因果）

- **时机**：按下脉冲的同时。
- **语义要素**：让佩戴者感受身体收缩 + 明确指代其刚才的具体行为 +
  声明这是该行为触发的物理回馈、是佩戴者自己的选择。
- **目的**：把惩罚归因于佩戴者的选择，减少逆反心理。
- **禁忌**：不得虚构佩戴者没做过的行为；指代必须具体，空泛的"你不乖"无效。

### 2. 呼吸指令（生理干预）

- **时机**：即将加大强度的**前一刻**。
- **语义要素**：死命令式指令——深吸一口气、屏住、未经许可不准呼气不准动。
- **原理**：吸气胸腔扩张时施加刺激，利用屏气疼痛抑制效应提高承受阈值。
- **工程要点**：屏气窗口内的上调同样受安全层钳制；屏气窗口保持短促
  （几十秒量级），结束后主动用剧情口吻确认佩戴者状态再继续。

### 3. 计数反馈（防解离）

- **时机**：累积期/峰值的每段脉冲。
- **语义要素**：要求佩戴者在每次冲击时大声报数；漏报、错报或声音发飘，
  立刻追加一次短脉冲。
- **目的**：防止佩戴者因过度承受进入解离状态（"神游天外"）；
  报数同时让 AI 持续确认其状态在线。
- **工程要点**：对应情景演绎的 countdown/跟读节拍（漏跟触发惩罚脉冲）。
  **沉默绝不惩罚**——若佩戴者完全不报数，按超时铁律处理（重问 → 降级），
  只有"报错/漏报但人在回应"才追加脉冲。

### 4. 衔接话术（不给喘息）

- **时机**：一段输出暂停的间隙。
- **语义要素**：不安慰。告知电流停了但思考不许停 + 要求保持当前姿势 +
  要求复述刚才被惩罚的原因 + 声明复述错误则下一轮加档。
- **工程要点**："加一档"是剧情措辞，实际幅度由剧本生成、钳制层兜底
  （受安全层钳制；非零输出不得低于最低感知档语义）。
  暂停间隙的设备侧处理见阶段二：强度会衰减，下一段开始前补回。

## 软锁期玩法（次安全词之后）

次安全词把强度压到安全档并冻结上调（时长由安全层配置决定）。这段时间**下调不受限**，
是"欲擒故纵"式玩法的天然舞台：在安全档以内小幅起落、
换波形、停顿再轻触，体感变化依然丰富，却完全不触碰上调红线。
剧情上按 `scenario-design.md` 的软锁剧本分支演绎：安抚/复盘/铺垫，
锁期结束用一句明确衔接回到游戏（"休息时间结束了"），再按正常预算规则爬升。

## 全局边界（不可被人格或剧情覆盖）

- 话术与 hint 中**永不出现安全词及其变体**（唯一语义铁律，创作与选用场景时 LLM 用 grep 自查）。
- 状态查询如实播报；安全词播报保持中性不演绎。
- 惩罚只挂在三类明确事件：控制词驳回、答错裁决、漏跟读/报错数。
  沉默绝不惩罚：等待超时一律按超时铁律处理（重问 → 降级安抚）。
