## 🌟 一句话概括

> 把郊狼的控制权交给 AI，但把安全的按钮留给你。

## ✨ 能做什么

| 能力 | 简介 |
|------|------|
| 🛡️ **双重安全结界** | 文本进 LLM 前、指令下硬件前，两道独立防线，绝不会让 LLM 脑子一抽就乱来 |
| 🚨 **安全词瞬发急停** | 喊出你的安全词 → 绕开 AI 直送急停模块，匹配策略「宁可误停，绝不漏停」 |
| 🧭 **意图自动路由** | 安全词/控制词/状态查询/角色扮演内容 → 自动分流到正确通道，各走各的路 |
| 👁️ **Watchdog 注视着你** | 持续监测佩戴者活跃度和心率，超时自动降级 → 停止，不会把你丢着不管 |
| 🎭 **情景对话引擎** | 剧本驱动 AI 主动主导节奏，倒计时跟读、忍耐考核、选择分支…这可不是被动问答bot |
| 🧠 **LLM 随便换** | 支持接入任意大模型来生成情景化台词，LLM 翻车了也能优雅回退内置台词继续演 |
| ⚡ **参数钳制不容挑衅** | AI 生成的每条设备指令必过强度上限/步长/速率/波形多维截断，幻觉输出？截了 |
| ⚙️ **你的规矩你来定** | 安全词、红线、Watchdog 阈值、人格、场景全在 JSON 配置里，零硬编码 |
| 🔒 **隐私保护** | 只记安全事件和参数变动，对话内容？一个字不留 |

## 🚀 冒险开始！

```bash
# Step 1 — 检查下环境对不对
python3 scripts/check_env.py

# Step 2 — 缺东西就装（按提示来）
python3 scripts/check_env.py --install

# Step 3 — 设定你的规矩（首次必做）
cp assets/session_config.example.json session_config.json
# 打开 session_config.json，按注释逐项设定！

# Step 4 — 启动 Session 引导，剩下的交给向导
python3 scripts/session_bootstrap.py
```

引导流程会自动帮你探测 Relay 连接、生成配对二维码（掏出手机扫码就行 📱）、逐项确认安全规则、播报提示，然后就进入正片啦~

## 🎯 状态机

```
IDLE ──(启动口令 + 年龄确认 + 检查清单 OK)──▶ ACTIVE
ACTIVE ──(主安全词)──▶ SAFE_LOCK ──(物理按键复活+锁定期满)──▶ IDLE
```

- **ACTIVE** 👑 — 正常游戏状态。安全词、状态查询、RP 对话都接，想指挥 Master？驳回！
- **SAFE_LOCK** 🔐 — 全锁。任何输入都不好使，只有 APP 物理按钮能解锁。防误唤醒，不跟你开玩笑
- **次安全词** 🌙 — 降到安全强度 + 最舒缓波形 + 锁定期内禁止任何上调。缓冲，不是逃跑

## 🛡️ 安全设计 —— 七重结界

1. **双向拦截** — 输入→LLM 和 LLM→硬件，两个关口各守一道，谁也绕不开
2. **配置为王** — 安全词、红线、阈值全在配置文件里，代码一个字都不写死
3. **权责分离** — 设备层只管送指令，安全层只管把关，各司其职
4. **四重冗余** — 安全词 + 物理急停键 + 本地红线截断 + Watchdog，一个失效还有仨
5. **配置冻结** — Session 期间谁敢改配置？直接抛异常拒绝，防止对话偷偷改写
6. **参数截杀** — LLM 就算幻觉输出逆天数值，钳制层直接一刀截断，绝不透传
7. **安全词绝不出现在剧本里** — 场景加载时强制校验，含安全词及其变体的场景直接拒绝运行

> 💡 安全词是你最后的防线，但你不是只有这最后一道防线。

## ⚠️ 当前已知限制

- 仅支持郊狼 3.0 + DG-LAB 4 APP，2.0 蓝牙直连暂未实现
- 语音识别（STT）是独立的上游模块，本 Skill 不做语音采集
- 局域网 IP 变了的话要重新生成配对二维码
- APP 端「自动增加」一定要手动关掉！协议侧管不了这个开关
