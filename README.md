# DGLAB AI Master

> **测试版 (Beta)** — 项目处于早期开发阶段，欢迎提交 Issue、PR 或任何形式的贡献！

以 AI "Master" 人格自主控制 **DG-LAB 郊狼 3.0**（Coyote 3.0 / DG-LAB 4 APP）电刺激设备的角色扮演 Session 编排与安全管控系统。

---

## 功能概述

- **安全层双重拦截** — 文本进入 LLM 之前 + 指令下发硬件之前，两处独立钳制，杜绝越权
- **安全词急停系统** — 硬急停全停锁定、软急停降级舒缓，匹配策略"宁误停不漏停"
- **意图过滤 & 路由** — 安全词直路由不经过 LLM；控制词、状态查询、RP 内容自动分流
- **Watchdog 守护** — 周期性检查佩戴者活跃度/心率，超时自动降级→停止
- **情景对话引擎** — 场景剧本驱动 AI 主动主导，支持倒计时跟读、忍耐考核、选择分支等互动原语
- **LLM 可插拔** — 注入任意 LLM 获得情景化台词与应答评判，LLM 异常时回退内置台词
- **参数钳制** — LLM 产生的每条设备指令必经强度上限、步长、速率、波形等多维截断
- **配置完全自主** — 安全词/红线/Watchdog/人格/场景全部由佩戴者在 JSON 配置中设定，零硬编码
- **隐私保护** — 只记录安全事件与参数变更，不记录任何对话内容

## 状态机

```
IDLE ──(启动口令 + 年龄验证 + 检查清单完成)──▶ ACTIVE
ACTIVE ──(主安全词)──▶ SAFE_LOCK ──(物理复位+锁定期满)──▶ IDLE
```

- **ACTIVE**：接受安全词、状态查询、RP 对话，控制类词汇自动驳回
- **SAFE_LOCK**：拒绝一切输入，仅物理按钮可解锁，防误唤醒
- **次安全词**：强度降至安全值 + 最舒缓波形 + 锁定期内禁止上调

## 安全设计原则

1. **双向拦截** — 安全层在文本→LLM 与 LLM→硬件两处各部署一次，互不绕行
2. **配置驱动** — 所有安全词/红线/阈值来自配置文件，代码不写死任何词条
3. **权力分离** — 设备层只管"送达"，不做安全决策；安全层不做剧情编排
4. **四重冗余** — 安全词（规则直路由）+ 非语音物理急停 + 本地红线截断 + Watchdog
5. **配置冻结** — Session 运行期间配置不可修改重载，防止被对话间接改写
6. **参数钳制** — LLM 幻觉输出异常值在钳制层截断，绝不透传硬件

## 限制与已知问题

- 仅支持郊狼 3.0 + DG-LAB 4 APP，不支持 2.0 蓝牙直连
- 语音识别（STT）为独立上游模块，本 Skill 不包含
- 局域网 IP 变化时需重新生成配对二维码
- APP 端「自动增加」功能必须手动关闭，协议侧无法控制
